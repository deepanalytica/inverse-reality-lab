- `/el-puente/original.html` — copia archivística del HTML fuente.

La edición web no resume ni sustituye el corpus. Añade navegación, lectura móvil/desktop, búsqueda de índice, progreso, anterior/siguiente, tema y acceso global al laboratorio.
