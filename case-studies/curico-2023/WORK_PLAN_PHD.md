# Work plan — commission PhD level

## Phase 0 — Governance and preregistration
Freeze vocabulary, schemas, hypotheses, evidence hierarchy, claim IDs and acceptance gates.
Exit: protocol reviewed; no inferential analysis before this gate.

## Phase 1 — Evidence acquisition and forensic registry
Collect authoritative records, station metadata, road/bridge reports, emergency records, planning documents, repair contracts, imagery and media evidence.
Outputs: sources.csv, observations.csv, assets.csv, claims.csv, provenance manifest.
Exit: critical event list has source coverage and unresolved conflicts ledger.

## Phase 2 — Geospatial normalization
Canonical CRS, geometries, uncertainty envelopes, catchments, roads, channels and infrastructure topology.
Exit: topology tests and geometry QA pass.

## Phase 3 — Meteorological/hydrological reconstruction
June/August forcing; antecedent accumulations; gauge failure/missingness; discharge where defensible.
Exit: event forcing dataset with uncertainty and station provenance.

## Phase 4 — MapBiomas longitudinal experiment
1999–2024 transitions; sub-basin/riparian/corridor statistics; matched comparison zones; fire/recovery context.
Exit: transition matrices and sensitivity results reproducible.

## Phase 5 — Earth-observation reconstruction
Sentinel-1/2/Landsat pre/post products; flood/change candidates; geomorphic scars; validation samples.
Exit: quality-controlled EO layers and confusion/error assessment where labels permit.

## Phase 6 — Cascade graph and infrastructure propagation
Fuse event chronology with drainage and infrastructure networks. Grade every edge D/I/H/R.
Exit: no untyped/unprovenanced edge in publication graph.

## Phase 7 — Hypothesis testing
Run pre-specified models, spatial diagnostics, sensitivity and alternative models.
Exit: results table includes effect/association, uncertainty, assumptions, robustness and failure cases.

## Phase 8 — Red team
Commission-style attack: alternative explanations, temporal inconsistencies, source conflicts, spatial artifacts, causal overreach, reproducibility.
Exit: zero unresolved critical findings; unresolved non-critical findings explicitly disclosed.

## Phase 9 — Publication package
Technical report, evidence atlas, reproducible data/code, interactive observatory and limitations.
Exit: clean-room reproduction of core outputs.

## Workstream ownership profiles
Hydrology; geomorphology; remote sensing/GIS; infrastructure/civil; disaster-risk/social exposure; statistics/causal inference; data/reproducibility engineering.

## Priority order
P0 provenance + topology + chronology.
P1 forcing + EO + MapBiomas.
P2 causal/associational models.
P3 UI/public narrative.
No visual sophistication may outrun evidentiary maturity.
