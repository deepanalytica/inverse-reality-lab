# Epistemic Corrections After Adversarial Study 001

The first five positive-control benchmarks were intentionally exploratory. The adversarial ablation study showed that some wording was too strong.

## Golden Gate

**Keep:** core precedence and functional need for temporary aerial accessibility can be strongly constrained when site/access information is included.

**Correct:** the terminal object does not uniquely identify the historical catwalk, climbing derrick, or exact balanced erection sequence.

Use:

> compatible / favored / functional-class recovered

instead of:

> exact mechanism recovered.

## Eiffel Tower

**Keep:** modular assembly and some temporary alignment/restraint class are strongly constrained.

**Correct:** exact prefabrication site, hydraulic-jack implementation, climbing steam crane and provisional bolt design are not uniquely recoverable from the terminal object.

## Hoover Dam

**Keep:** river-control topology and thermal segmentation become strongly constrained when site hydrology and mass-concrete physics are included.

**Correct:** active embedded cooling pipes require a time/schedule constraint to become strongly favored; terminal state alone does not uniquely identify them.

## Empire State Building

**Major correction:** JIT logistics, extreme trade pipeline and jumping derricks are not terminal-state deductions.

They require additional variables including:

- urban site/storage constraints;
- construction-duration objective;
- throughput/logistics;
- access model.

Correct formulation:

> terminal structure + site + schedule + logistics favor these process classes.

## Sydney Opera House

**Keep:** a shared geometric generator can be inferred directly from sufficiently accurate geometry.

**Correct:** exact telescopic erection arch, on-site factory, rail-mounted cranes and tile-bed production system are not uniquely recoverable from terminal geometry.
