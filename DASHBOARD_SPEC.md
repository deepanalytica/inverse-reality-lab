# Especificación del Dashboard 3D/4D de IRL

## Objetivo

El dashboard convierte la teoría de Inverse Reality Laboratory en una herramienta visual auditable. La interfaz muestra el objeto, la evidencia, las hipótesis y las restricciones dentro del mismo espacio de trabajo.

## Significado de 4D

En IRL, 4D significa:

\[
\text{geometría 3D}
+
\text{estado causal/inferencial}
\]

El control temporal representa una secuencia de estados de reconstrucción. Se interpreta como progreso inferencial, no como una fecha histórica automática.

## Módulos

1. Visor 3D: envolvente, cursos, cámaras, Big Void, North Face Corridor, detectores, fuerzas, dominio subsuperficial y bloques proxy.
2. Estado causal: estado seleccionado, situación inmediatamente anterior, condiciones requeridas, transición siguiente y evidencia.
3. Hipótesis: resumen, evidencia, deducciones, predicciones y observaciones discriminantes.
4. Evidencia: fuente, tipo, año, enlace y función dentro del modelo.
5. Anomalías: vacíos publicados, continuaciones abiertas y volúmenes de búsqueda.
6. Comparativa: Khufu activo; Khafre, Menkaure, Dahshur y Stonehenge como casos planificados.
7. Biblioteca: Markdown, paper, LaTeX, benchmarks, glosario y especificaciones.

## Estados epistemológicos

- OBSERVED
- PUBLISHED
- DERIVED
- INFERRED
- HYPOTHESIS
- COUNTERFACTUAL
- UNKNOWN

## Modelo bloque-a-bloque

La versión v1.1 implementa bloques proxy paramétricos para probar masa, selección, acceso y fuerzas.

\[
B_i=\{G_i,\rho_i,m_i,z_i,\text{curso},\text{estatus}\}
\]

y:

\[
m_i=\rho_iV_i.
\]

La geometría exacta de cada bloque real requiere un dataset de levantamiento bloque-a-bloque. El dashboard distingue ambos niveles.

## Fuentes 3D

La referencia institucional principal es Digital Giza / Harvard Giza Project. El visor IRL utiliza una geometría propia paramétrica para mantener reproducibilidad, control de licencias y asociación directa entre entidades y evidencia.

## Salida científica

Para cualquier entidad, el dashboard debe responder:

- qué observamos;
- qué inferimos;
- qué tuvo que ocurrir antes;
- qué condiciones habilitan la transición siguiente;
- qué evidencia sostiene la afirmación;
- qué medición futura reduciría la incertidumbre.
